# PRD v0.2 요약 (TapCook 한국 버전)

원본: 구글 스프레드시트 "밀프렙 장보기 앱 PRD v0.2". 상태 표기는 확정, 제안, 가정, 미결.

## 개요
- 서비스 정의: 일주일에 한 번 장을 보고 조리해 여러 끼를 나눠 먹는 밀프렙 사용자에게 메뉴와 장보기 목록을 자동으로 구성해 주는 모바일 웹앱 (확정)
- 서비스 목표: 무엇을 먹을지에 대한 고민과 금액적 부담을 줄이도록 일주일치 메뉴와 장보기 목록을 대신 구성 (확정)
- 대상 사용자: 1인 중심으로 시작해 가족 단위로 확장. 식비 절약 목적과 체중 관리 목적 모두 포함 (확정)
- 비목표: 질환 대상 표시와 효능 표방, 냉장고 재료 입력(단, 집에 있는 양념 체크는 MVP 포함, 2026-10-23), 마트별 가격, 알림, 점심 포함 14끼는 후속 단계 (확정)

## 사용자 흐름
1. 입력: 내 설정(인원수 1인 기본, 식단 분류 한식/고단백, 칼로리 한 끼 기준, 먹고 싶은 단백질, 집에 있는 양념)은 처음 한 번 묻고 저장. 이번 주 조건(식사 날짜 기본 다음 주 평일·달력으로 변경)은 매주 입력. 메뉴 개수(1~5개, 기본 2개)는 추천 메뉴 화면에서 추가·삭제로 조절하고 지난 개수를 기억. 끼니 수는 선택한 날짜로 자동 계산, 조리일은 입력받지 않음
2. 메뉴 자동 구성: 조건 필터 후 재료가 겹치는 조합 우선. 한 번 눌러 교체
3. 레시피 확인: 재료, 분량, 조리 단계, 1인분 영양정보, 보관 방법
4. 장보기 목록: 판매 단위 계산, 남는 재료는 같은 주 다른 메뉴에 우선 활용
5. 구매: 재료별 쿠팡 링크
6. 예산: 버전 A(예산 먼저) 또는 버전 B(예산 마지막, 초과 시 교체 제안)

## 기준과 규칙
- 고단백 기준: 1인분 단백질 30g 이상, 600kcal 이하, 설정값으로 분리 (확정)
- 추가 기준: 단백질 열량 비중 25% 이상, 나트륨·포화지방 표시, 단백질 공급원 분산 (제안)
- 조리 주기: 일주일에 한 번. 조리일은 첫 식사일 전날로 가정, 보관 안내 화면에서만 변경 (확정)
- 냉장·냉동 분배: 초안(14끼 기준 절반씩)과 날짜 기준안(조리 후 3일 이내 냉장, 이후 냉동) 중 미결
- 보관 온도: 냉장 5도 이하, 냉동 영하 18도 이하, 조리 후 상온 방치 금지 (제안, 공식 문서 확인 필요)
- 쿠팡: 쿠팡 파트너스 이용, 승인 절차와 수수료 고지 필요, 가격은 저장하지 않음 (확정)
- 레시피 데이터: 분류별 30~50개, 재료 표준화, 사람 검수, 조리 단계는 직접 작성 (확정/제안)
- 플랫폼: 모바일 우선 웹앱으로 시작해 앱 바인딩으로 확장, 개발은 Claude 주도 (확정)

## 미결 사항
1. 서비스 이름
2. 냉장·냉동 분배 규칙
3. 냉장 기준 일수 3일 또는 4일, 식약처 공식 기준
4. 칼로리 선택 구간 값
5. 단백질 열량 비중과 나트륨 기준
6. 쿠팡 파트너스 API 이용 조건과 가격 저장 가능 여부
7. 참가격 실제 품목 범위와 신선식품 보완 데이터
8. 코리안넷 이용 조건
9. 로그인 없이 시작할지 최종 결정
10. 마트별 가격 데이터 확보 가능성
11. 식사 날짜 최대 선택 기간(14일 제안)
