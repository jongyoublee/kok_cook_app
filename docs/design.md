## 1. 색 (I7, 확정)
블랙/화이트를 기본으로 하고, 테라코타 계열 강조색을 두 단계로 나눠 **날짜·진행·주의**를 알리는 곳에만 쓴다. 값은 한 곳(설정 또는 CSS 토큰)에서 관리한다.

| 토큰 | 값 | 흰 바탕 대비 | 쓰는 곳 | 금지 |
|---|---|---|---|---|
| ink | #111214 | | 글자, 버튼, 선택된 탭, 제목, 큰 금액 | |
| sub | #6B6D71 | | 보조 글자, 메타 정보 | |
| line | #E6E6E3 | | 구분선, 테두리 | |
| bg | #F4F4F2 | | 화면 바탕 | |
| surface | #FFFFFF | | 카드·목록 바탕 | |
| accent-text (진하게) | #A3471F | 6.0:1 (회색 바탕 5.5:1) | 요일, 장보기 날짜, 설명 링크("가격은 이렇게 계산해요"), "○원 남아요", 태그 글자, "함께 써요" | |
| accent-mark (밝게) | #C8693F | 3.8:1 | 진행 막대(예산·구매), 요일 앞 점, 구매 체크 원, 아이콘 선, 경고 테두리 | **글자에 쓰지 않는다** |
| accent-tint (연한 바탕) | #F6E9E2 | | 강조 태그("냉동 가능", "오래 써요") 배경, 경고 배경 | 위 글자는 accent-text 또는 #7A3518 |
| warn-ink | #7A3518 | 연한 바탕 위 7.5:1 | 경고 문구 글자 | |

- 버튼과 선택 상태는 계속 검정이다. 강조색으로 버튼을 칠하지 않는다.
- 그림자는 따뜻한 검정을 옅게: 카드 `0 1px 2px rgba(23,21,19,.06)`, 떠 있는 메뉴 `0 6px 20px rgba(23,21,19,.14), 0 1px 2px rgba(23,21,19,.08)`.
- 기존 원칙은 유지: 이모지 없음, 선택 칸은 흰 바탕에 굵은 검정 테두리.

## 2. 글자 체계
- **소제목(eyebrow)**: 11px, 굵게(800), 자간 0.12em, sub 색. 구역 머리(예: "다음 주 저녁")에는 아래 2px 검정 선.
- **큰 숫자**: 금액·시간은 28~30px 굵게, 숫자 폭 고정(`font-variant-numeric: tabular-nums`).
- **화면 제목**: 24px 굵게. 메뉴 이름 15px 굵게, 메타 12px sub.
- 한글 글꼴은 지금 그대로 둔다. 제목용 글꼴(예: Pretendard 자체 포함)은 별도 결정.

## 3. 떠 있는 하단 메뉴 (I8, 확정)
- 화면 아래에서 띄운 흰 알약 바: 좌우 14px, 아래 14px + `env(safe-area-inset-bottom)`, 높이 52px(안쪽 6px), 둥글기 999px, 바탕 `rgba(255,255,255,.92)`와 흐림(backdrop-filter blur 12px), 위 그림자.
- 탭 4개: **이번 주 / 장보기 / 보관 / 내 설정**. 선택된 탭만 검정 알약(높이 40px)에 아이콘과 이름, 나머지는 아이콘만(sub 색). 각 탭은 최소 44px 터치 영역, `aria-label`과 `aria-current="page"`.
- 아이콘: 24×24 viewBox, 선 1.8px, 둥근 끝. 직접 그린 SVG 4개(달력, 장바구니, 눈꽃, 사람). 아이콘 라이브러리는 추가하지 않는다.
- 화면 콘텐츠 아래에 메뉴 높이만큼 여백(약 92px)을 둬서 가리지 않게 한다.
- **처음 설정(SetupScreen)과 레시피 관리(AdminScreen)에서는 숨긴다.**
- 하단 고정 버튼("메뉴 만들기", "메뉴 확정" 등)이 있는 화면은 버튼을 메뉴 바로 위에 쌓는다.

### 탭별 화면
| 탭 | 확정한 계획이 있을 때 | 없을 때 |
|---|---|---|
| 이번 주 | 확정한 메뉴(홈) + [이번 주 \| 다음 주] 탭 | 이번 식단 조건 화면(메뉴 만들기) |
| 장보기 | 확정한 장보기 목록 | "아직 확정한 메뉴가 없어요" 빈 화면과 "메뉴 만들기" 버튼 |
| 보관 | 보관 방법(지금 장보기 화면의 보관 탭을 독립 화면으로) | 빈 화면 안내 |
| 내 설정 | 이번 식단 조건 화면(인원·식단·단백질·탄수화물·양념·예산), 내 데이터 지우기 | 같음 |

- 레시피 상세는 탭이 아니라 어느 탭에서든 들어가는 하위 화면이다. 뒤로 가기는 들어온 탭으로 돌아간다. 하위 화면에서도 하단 메뉴는 보인다.
- 장보기 화면 안의 [장보기 목록 | 보관 방법] 탭은 보관이 독립 탭이 되면 없앤다(보관 내용은 보관 탭으로 이동).

## 4. 홈: 이번 주 / 다음 주 (B13, 확정)
- 위쪽: 서비스 이름(KokCook), 그 아래 [이번 주 | 다음 주 | 날짜 범위] 알약 탭. 선택된 탭은 검정 테두리·굵게.
- **이번 주**: 확정한 계획을 보여 준다(메뉴 행 읽기 전용 + 교체는 B8 경고를 거침).
- **다음 주**: 지금의 추천 메뉴 화면(조건으로 만든 메뉴, 추천안, 메뉴 추가, 확정). 만들 계획이 없으면 "다음 주 메뉴 만들기" 버튼.
- 순서(다음 주 기준): 요약 카드(예상 금액, 예산 막대·"○원 남아요"(버전 A), 끼니·인원·장보기 날짜, 칼로리 요약 한 줄) → 추천안 칩(장보기 간단 / 가장 저렴 / 집 양념으로 / 한 주 플렉스) → 소제목 "다음 주 저녁" → 메뉴 행 → 메뉴 추가 → "이 레시피는 어떤가요?" 카드 → 하단 고정 "메뉴 확정"(떠 있는 메뉴 위).

## 5. 메뉴 행 (B14, 확정)
- 카드 테두리 대신 흰 목록 한 장 안의 행, 행 사이 가는 구분선.
- 왼쪽 56px 정사각 둥근(12px) 사진 자리. 사진이 없으므로 회색 바탕에 accent-mark 선 아이콘.
- 가운데: 요일 소제목(accent-text 11px 굵게, 앞에 accent-mark 6px 점, 예: "월 · 수 · 금"), 메뉴 이름(15px 굵게, 두 줄까지), 메타 한 줄(1인분 예상 금액 · 단백질 · kcal), 태그(강조 태그는 tint 바탕 + accent-text, 일반 태그는 테두리만).
- 오른쪽: "교체" 알약 버튼(흰 바탕, 테두리). 지금의 오른쪽 위 X 삭제와 "다시 안 보기"는 … 메뉴(행 오른쪽 위)로 옮긴다.

## 6. 장보기 요약 카드 (D11, 확정)
- 제목 "장보기" 아래 부제: "다음 주 · 10/26~10/30 · **10/25(일) 장보기 ✎**"(장보기 날짜 accent-text, 누르면 바로 수정).
- 카드: 소제목(기간), 큰 예상 금액, "12개 중 4개 샀어요"와 accent-mark 진행 막대, "가격은 이렇게 계산해요" 링크(accent-text).
- 목록: 코너 소제목, 행마다 원형 체크(체크하면 accent-mark 원과 흰 체크, 글자 회색 취소선), 이름, "판매 단위 × 개수 · 남는 양", "○○·○○에 함께 써요"(accent-text), 오른쪽 가격과 쿠팡 버튼. 양념 묶음 머리에 "한 번 사면 오래 써요", 해당 항목에 "오래 써요" 강조 태그.
- 지금 하단 고정 합계는 요약 카드로 올라가므로 없앤다. 공유(D10)와 직접 추가(D9)는 제목 오른쪽 아이콘·목록 끝에 둔다.

## 7. 레시피 상세 다듬기 (C5, 제안)
위쪽 큰 숫자(조리 시간, 인분 조절, 재료 수), 조리 단계 구간 묶기("손질 / 조리 / 소분·보관")와 구간 시간, 하단 고정 "다 만들었어요"(B12 요리 후 평가로 연결). 레시피 데이터에 구간 정보가 필요해 다음 단계로 둔다.

## 8. 구현 순서 (개발 세션용)
코드 수정 전 이 순서로 계획을 확인받고, 단계마다 테스트와 커밋을 한다(CLAUDE.md 작업 방식).

1. **토큰**: `src/index.css`(Tailwind v4 `@theme`) 또는 `src/ui.ts`에 위 색·그림자 토큰을 한 곳에 정의. 기존 회색·검정 클래스는 토큰으로 바꾼다. 강조색은 아직 쓰지 않는 상태로 시작.
2. **하단 메뉴(I8)**: `src/components/BottomNav.tsx`와 아이콘 SVG 4개. `App.tsx`의 화면 상태를 "탭 + 하위 화면(레시피)" 구조로 바꾸고, 처음 설정·관리 화면에서 숨김. 각 화면 아래 여백 정리, 하단 고정 버튼을 메뉴 위로.
3. **보관 탭 분리**: `StorageTab`을 독립 화면으로, 장보기 화면의 내부 탭 제거.
4. **홈 이번 주 / 다음 주(B13)**: 확정 계획(plan)과 만들 계획(menu)을 탭으로 나눠 보여 줌. 빈 상태 화면.
5. **메뉴 행(B14)**: `MenuScreen`의 카드를 행으로, … 메뉴(다시 안 보기·삭제), 요약 카드와 추천안 칩 배치 순서 정리.
6. **장보기 요약 카드(D11)**: 큰 금액, 구매 진행 막대, 부제의 장보기 날짜 수정, 원형 체크 스타일, 하단 고정 합계 제거.
7. **강조색 적용(I7)**: 위 표의 쓰는 곳에만 accent 토큰 적용. 글자에 accent-mark를 쓰지 않았는지 확인.
8. **확인**: 휴대폰 너비(390px)에서 화면 캡처로 겹침·가림 확인, 기존 테스트 통과, 키보드 포커스와 `aria` 확인.

9. **로고(I9)**: 앱 머리(이번 주 홈 왼쪽 위), 처음 설정 첫 화면, 브라우저 탭 아이콘(`public/favicon.svg`를 `docs/brand/kokcook-icon.svg` 기반으로 교체), `index.html`의 title을 KokCook으로. 워드마크 글꼴(Plus Jakarta Sans 800) 불러오기.

### 지켜야 할 것
- 기능과 계산 로직(메뉴 구성, 장보기 계산, 예산, 보관 분배)은 바꾸지 않는다. 화면 구조와 스타일만 바꾼다.
- 하단 메뉴와 탭 상태는 새로고침 후에도 마지막 탭을 기억할 필요는 없다(필요하면 기기 저장에 추가).

## 9. 로고와 앱 아이콘 (I9, 확정 2026-10-24)

### 워드마크
- 표기 **KokCook**: Kok과 Cook 두 단어의 머리만 대문자. KOKCOOK, kokcook, KoKcook은 쓰지 않는다.
- 글꼴 Plus Jakarta Sans ExtraBold(800), 자간 -0.03em(18px 이하는 -0.02em), 색 ink #111214.

### 아이콘: 셰프 모자 (세 봉우리)
- 아웃라인만, 채우지 않는다. 몸통 선은 ink #111214, **모자 띠 한 줄만 강조색 밝게 #C8693F**.
- 원본: `docs/brand/kokcook-icon.svg` (24×24 viewBox). 몸통 경로 `M7.5 20h9a.5.5 0 0 0 .5-.5v-5.2a3.8 3.8 0 1 0-2.1-7.1 4 4 0 0 0-5.8 0A3.8 3.8 0 1 0 7 14.3v5.2a.5.5 0 0 0 .5.5z`, 띠 `M7 16.6h10`.
- 크기별 선 굵기(viewBox 단위, 몸통 / 띠): 64px 이상 1.6 / 2.1, 40~63px 1.7 / 2.1, 28px 1.9 / 2.4, 24px 이하 2.2 / 2.8. 작을수록 굵게 해 뭉개지지 않게 한다. 최소 18px.

### 기본 로고 (아이콘 + 워드마크)
- **가로형**(기본): 모자 + KokCook. 모자 높이는 글자 높이의 약 1.25배, 사이 간격은 모자 너비의 약 20%. 앱 머리는 모자 28px + 글자 22px, 간격 6px.
- **세로형**: 모자 위, KokCook 아래, 간격 10~14px. 처음 설정 첫 화면, 앱 소개용.
- 로고에는 테두리 상자를 씌우지 않는다(상자는 앱 아이콘에서만).

### 앱 아이콘
- 흰 바탕 둥근 사각형(모서리 약 22%) 안에 위 아이콘. 원본: `docs/brand/kokcook-app-icon.svg` (1024×1024).
- 스토어·홈 화면용은 바깥 테두리 없이, 앱 화면 안에 그릴 때는 #E6E6E3 1px 테두리와 옅은 그림자.
- 브라우저 탭 아이콘은 24px 규칙(선 2.2 / 2.8)을 따른다.

### 하지 말 것
- 모자 몸통이나 글자를 강조색으로 칠하기, 띠를 검정으로 바꾸기(로고·아이콘 모두 띠 강조색으로 통일)
- 모자를 채우기, 그림자·그라데이션 넣기, 비율을 늘리거나 줄이기
- 어두운 바탕 위에 검정 그대로 쓰기(어두운 바탕용은 아직 정하지 않음. 필요하면 흰 선 + 같은 강조색 띠로 별도 결정)
