# 와이어프레임 설명 (저해상도)

화면 기준 날짜 예시: 오늘 10/22(목), 다음 주 10/26(월)~11/1(일). 모든 숫자와 메뉴 이름은 예시다.

## 공통. 색과 하단 메뉴 (I7, I8) — 2026-10-24
- 블랙/화이트 + 테라코타 강조색 두 단계(작은 글자 #A3471F, 그래픽 #C8693F, 연한 바탕 #F6E9E2). 날짜·진행·주의에만 쓴다
- 화면 아래에 떠 있는 흰 알약 메뉴: 이번 주 / 장보기 / 보관 / 내 설정. 선택된 탭만 검정 알약에 아이콘과 이름. 처음 설정·관리 화면에서는 숨김
- 로고(I9): 가로형 로고(셰프 모자, 띠만 강조색 + KokCook)를 이번 주 홈 왼쪽 위에, 세로형은 처음 설정 첫 화면에
- 자세한 값과 배치는 docs/design.md

## 0-0. 사용법 안내 (I10) — 2026-10-24
- 처음 실행 때 처음 설정 앞에 한 번, 내 설정의 "사용법 보기"로 다시 열기
- 위쪽 이전 버튼(첫 장은 숨김)과 오른쪽 "건너뛰기". 가운데 회색 원 안에 단색 선 그림(강조할 부분만 #C8693F), 제목, 설명 두 줄
- 카드: "집에 있는 재료부터 골라요"(바구니와 체크) → "마음에 안 들면 한 번에 바꿔요"(카드 두 장과 교체 화살표) → "장보기 목록은 알아서 계산해요"(체크 목록) → "보관은 날짜에 맞춰 알려 줘요"(달력과 눈꽃)
- 아래 점 4개(지금 장은 긴 검정 점)와 "다음"(마지막은 "시작하기"). 옆으로 밀어도 넘어감

## 0. 처음 설정, 한 번만 (A12, A1, A2, A8~A10) — 2026-10-23, 2026-10-24 재료 단계 추가
- 블랙/화이트 테마. 이모지 없음(단색 아이콘은 나중에)
- 위쪽 6칸 진행 막대, 이전 버튼, "n/6"(2026-10-23 식단 단계 삭제, 2026-10-24 재료 단계 추가). 질문 위에 항목명. 질문은 화면 세로 가운데, 하단 고정 "다음"(마지막은 "완료")
- 선택 칸은 같은 모양의 사각 칸, 고르면 흰 바탕에 굵은 검정 테두리. 재료 선택 칸(단백질, 탄수화물, 양념)은 빈칸으로 시작
- 1/6 "집에 있는 재료부터 골라 볼까요?" (세로형 로고 아래): 육류·달걀, 수산, 두부·콩, 채소, 곡류 코너별 3열 칸, "N개 선택". 하나도 안 고르면 버튼이 "없어요, 다음". 고른 고기·생선·두부로 다음 단백질 칸을 미리 채움 (2026-10-24)
- 2/6 "몇 명이 먹나요?": - 1 + (기본 1명)
- 3/6 "어떤 단백질을 먹고 싶나요?": 돼지고기, 소고기, 닭고기, 생선, 해산물, 두부·콩, 달걀(1개 이상), "전부 좋아요", "조건에 맞는 메뉴 N개"
- 4/6 "무엇과 함께 먹고 싶나요?": 밥, 면·파스타, 감자, 고구마(1개 이상), "전부 좋아요"
- 5/6 "집에 이미 있는 양념을 골라 주세요": 기본 양념 10개 3열 그리드, 아래 "한식·양식 양념 더 보기 (19)" 버튼으로 한식 양념·양식 양념 묶음을 펼침
- 6/6 "언제 먹을 건가요?": 빠른 선택 3개와 달력(1-2와 같은 달력을 화면 안에), 조리일 안내, "모든 메뉴는 한 끼 600kcal 이하 기준으로 만들었어요", 전문가 상담 안내

## 1-1. 이번 식단 조건 (A1~A3, A8~A10, A7)
- 제목 "이번 식단 조건". 요약 카드 없이 모든 항목을 바로 고친다
- 맨 위 "집에 있는 재료"(처음 설정 1/6과 같은 칸). 고른 고기가 먹고 싶은 단백질에 없으면 "단백질에 넣기" 안내 (2026-10-24, A12)
- 먹을 날짜: "10/26(월) ~ 10/30(금) / 다음 주 평일, 저녁 5끼" 카드와 "달력" 버튼, "조리일은 10/25(일)로 가정해요"
- 인원 - 1 +, 먹고 싶은 단백질, 함께 먹을 탄수화물, 집에 있는 양념(기본 10개 + 더 보기 버튼)
- 예산 입력 칸은 예산 버전 A에서만 표시 (2026-10-24: 기본은 예산 끔이라 보이지 않음, F3)
- 하단 고정: "조건에 맞는 메뉴 N개", "메뉴 만들기", 전문가 상담 안내

## 1-2. 조건 입력, 달력 열림 (A2)
- 달력 버튼을 누르면 아래에서 시트가 올라온다. 뒤 화면은 흐리게
- 시트 제목 "먹을 날짜 선택", 닫기 버튼
- 빠른 선택: 다음 주 평일, 다음 주 매일, 선택 해제
- 월 이동이 가능한 달력. 지난 날짜는 흐리게, 오늘 표시, 선택한 날짜 강조, 첫 식사일 전날에 "조리" 표시
- "5일 선택, 최대 14일" 안내
- "선택 완료" 버튼을 누르면 닫히고 요약 카드가 바뀐다

## 2. 추천 메뉴 (B1~B6)
- 제목 "다음 주 메뉴"
- 추천안 3칸: "장보기 간단 / 재료 7가지", "가장 저렴 / 약 36,800원", "집 양념으로 / 새 양념 2가지". 누르면 그 조합으로 바뀜. 예산 버전 A는 "한 주 플렉스 / 새우·연어 · 약 53,500원"을 더해 2×2 (2026-10-23)
- 메뉴 카드: 사진 자리, 메뉴 이름, "단백질 34g, 540kcal", 먹는 요일(예: 월, 수, 금 3끼), "교체" 버튼
- "메뉴 추가 (2/5)" 버튼, 카드 오른쪽 위 X로 삭제. 메뉴 개수는 여기서만 조절하고 다음 주에 이 개수로 시작 (2026-10-23)
- "겹치는 재료: 대파, 양파, 간장"
- 예상 금액 막대
- 확정 버튼 위 "이 레시피는 어떤가요?" 카드: 메뉴 이름, 맛·조리법, "남는 돼지고기 240g을 써요", "추가 예상 금액 약 2,000원", [메뉴에 추가] [괜찮아요] (2026-10-23)
- 칼로리 요약: "저녁 5끼 · 한 끼 평균 약 520kcal · 단백질 36g", "5끼 합계 약 2,600kcal · 1인 기준 추정치" (2026-10-23)
- 하단 "메뉴 확정"
- 2026-10-24 개편안(B13, B14): 홈 위쪽 [이번 주 | 다음 주 | 날짜] 탭. 다음 주 순서는 요약 카드(예상 금액·예산 막대·장보기 날짜·칼로리 한 줄) → 추천안 칩 → 소제목 "다음 주 저녁" → 메뉴 행(요일 소제목·이름·1인분 금액·단백질·kcal·태그·교체 알약·… 메뉴) → 메뉴 추가 → "이 레시피는 어떤가요?" → "메뉴 확정"(떠 있는 메뉴 위)

## 3. 레시피 상세 (C1~C4)
- 뒤로 가기와 메뉴 이름, 사진 자리
- 영양 칩: 칼로리, 탄수화물, 단백질, 지방
- 재료 목록(끼니 수 기준 분량), 조리 단계
- "냉동 가능", "냉장 3일" 표시(임시값 안내)
- "나눠 담기": 다 만든 뒤 저울로 1인분 약 Ng씩 n개로 나눠 담기, 총 무게 (2026-10-23)
- 메뉴 화면과 장보기 화면에서 메뉴를 눌러 들어오고, 뒤로 가기로 돌아간다 (2026-10-23)
