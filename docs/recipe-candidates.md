# 레시피 후보 목록

웹에서 찾은 레시피의 **재료 구성만** 모아 둔 검수용 목록이다. 원문 글, 조리 단계, 사진은 옮기지 않는다(CLAUDE.md). 검수를 통과한 레시피만 조리 단계를 새로 써서 `src/data/recipes.ts`에 넣는다.

## 쿠팡 판정 기준
- **O** 로켓배송으로 바로 구매 가능 (가공식품, 양념, 냉동)
- **F** 로켓프레시로 구매 가능 (채소, 생고기, 유제품 등 신선식품). 와우 회원과 배송 지역 조건이 있다
- **X** 쿠팡에서 구하기 어려움
- 판정은 상품 구성에 대한 추정이다. 쿠팡 파트너스 API 승인 뒤 실제 확인으로 바꾼다
- 우선순위: 구매 가능(O+F) 비율 80% 이상. 후보가 적으면 60% 이상까지. X가 3개 이상이면 "구하기 어려운 재료 많음"으로 분리한다
- 밥(쌀)은 앱에서 다루지 않으므로 판정에서 뺀다

### 1차 결과 요약
- 10개 모두 구매 가능 비율 100%다. 한식 재료는 쿠팡(로켓배송 + 로켓프레시)에서 거의 다 살 수 있어 80% 기준으로는 걸러지는 레시피가 없다.
- 다만 신선식품은 모두 **로켓프레시**다. "로켓배송만"으로 기준을 좁히면 대부분 50% 안팎으로 떨어진다. 기준을 어느 쪽으로 볼지 정해야 한다.
- 실제로 거를 때 더 중요한 기준은 쿠팡보다 **밀프렙 적합성**(냉동·냉장 보관, 데워 먹었을 때 품질)이다. 8번 참치마요, 7번 숙주볶음, 1번 우동, 9번 크림 파스타는 보관 품질이 약하다.
- 우리 기준(고단백: 1인분 단백질 30g 이상, 600kcal 이하)을 맞추려면 1, 3, 6, 9번은 분량 조정이 필요하다. 영양정보는 아직 계산하지 않았다.

- 10개 모두 80% 이상이고, X 재료가 3개 이상인 레시피는 없다. 미국식 메뉴도 한국 쿠팡에서 대부분 살 수 있다.
