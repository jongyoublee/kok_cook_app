# 와이어프레임 설명 (저해상도)

화면 기준 날짜 예시: 오늘 10/22(목), 다음 주 10/26(월)~11/1(일). 모든 숫자와 메뉴 이름은 예시다.

## 0. 처음 설정, 한 번만 (A1, A2, A8~A10) — 2026-10-23
- 블랙/화이트 테마. 이모지 없음(단색 아이콘은 나중에)
- 위쪽 5칸 진행 막대, 이전 버튼, "n/5"(2026-10-23 식단 단계 삭제). 질문 위에 항목명. 질문은 화면 세로 가운데, 하단 고정 "다음"(마지막은 "완료")
- 선택 칸은 같은 모양의 사각 칸, 고르면 흰 바탕에 굵은 검정 테두리. 재료 선택 칸(단백질, 탄수화물, 양념)은 빈칸으로 시작
- 1/5 "몇 명이 먹나요?": - 1 + (기본 1명)
- 2/5 "어떤 단백질을 먹고 싶나요?": 돼지고기, 소고기, 닭고기, 생선, 해산물, 두부·콩, 달걀(1개 이상), "전부 좋아요", "조건에 맞는 메뉴 N개"
- 3/5 "무엇과 함께 먹고 싶나요?": 밥, 면·파스타, 감자, 고구마(1개 이상), "전부 좋아요"
- 4/5 "집에 이미 있는 양념을 골라 주세요": 기본 양념 10개 3열 그리드, 아래 "한식·양식 양념 더 보기 (19)" 버튼으로 한식 양념·양식 양념 묶음을 펼침
- 5/5 "언제 먹을 건가요?": 빠른 선택 3개와 달력(1-2와 같은 달력을 화면 안에), 조리일 안내, "모든 메뉴는 한 끼 600kcal 이하 기준으로 만들었어요", 전문가 상담 안내

## 1-1. 이번 식단 조건 (A1~A3, A8~A10, A7)
- 제목 "이번 식단 조건". 요약 카드 없이 모든 항목을 바로 고친다
- 먹을 날짜: "10/26(월) ~ 10/30(금) / 다음 주 평일, 저녁 5끼" 카드와 "달력" 버튼, "조리일은 10/25(일)로 가정해요"
- 인원 - 1 +, 먹고 싶은 단백질, 함께 먹을 탄수화물, 집에 있는 양념(기본 10개 + 더 보기 버튼)
- 예산 입력 칸은 예산 버전 A에서만 표시
- 하단 고정: "조건에 맞는 메뉴 N개", "메뉴 만들기", 전문가 상담 안내

## 1-2. 조건 입력, 달력 열림 (A2)
- 달력 버튼을 누르면 아래에서 시트가 올라온다. 뒤 화면은 흐리게
- 시트 제목 "먹을 날짜 선택", 닫기 버튼
- 빠른 선택: 다음 주 평일, 다음 주 매일, 선택 해제
- 월 이동이 가능한 달력. 지난 날짜는 흐리게, 오늘 표시, 선택한 날짜 강조, 첫 식사일 전날에 "조리" 표시
- "5일 선택, 최대 14일" 안내
- "선택 완료" 버튼을 누르면 닫히고 요약 카드가 바뀐다

## 2. 추천 메뉴 (B1~B6)
- 제목 "다음 주 메뉴"
- 메뉴 카드: 사진 자리, 메뉴 이름, "단백질 34g, 540kcal", 먹는 요일(예: 월, 수, 금 3끼), "교체" 버튼
- "메뉴 추가 (2/5)" 버튼, 카드 오른쪽 위 X로 삭제. 메뉴 개수는 여기서만 조절하고 다음 주에 이 개수로 시작 (2026-10-23)
- "겹치는 재료: 대파, 양파, 간장"
- 예상 금액 막대
- 칼로리 요약: "저녁 5끼 · 한 끼 평균 약 520kcal · 단백질 36g", "5끼 합계 약 2,600kcal · 1인 기준 추정치" (2026-10-23)
- 하단 "메뉴 확정"

## 3. 레시피 상세 (C1~C4)
- 뒤로 가기와 메뉴 이름, 사진 자리
- 영양 칩: 칼로리, 탄수화물, 단백질, 지방
- 재료 목록(끼니 수 기준 분량), 조리 단계
- "냉동 가능", "냉장 3일" 표시(임시값 안내)
- "나눠 담기": 다 만든 뒤 저울로 1인분 약 Ng씩 n개로 나눠 담기, 총 무게 (2026-10-23)
- 메뉴 화면과 장보기 화면에서 메뉴를 눌러 들어오고, 뒤로 가기로 돌아간다 (2026-10-23)

## 4. 장보기 목록 (D1~D6, G1~G3)
- "10/25(일) 조리 전까지 구매" 안내
- 코너별 묶음(채소, 육류와 달걀 등), 항목마다 체크 상자, 판매 단위 수량, 쿠팡 링크 아이콘
- 남는 재료 활용 안내
- 구매한 항목은 취소선
- 쿠팡 수수료 고지 문구, 예상 합계
- 하단 "구매 시작"
- 2026-10-23 구현: 위쪽에 메뉴별 레시피 바로가기, 항목마다 "판매 단위 × 개수 · 필요량 · 남는 양"과 함께 쓰는 메뉴, 집에 있어서 뺀 양념은 접힌 칸, 하단 고정 예상 합계와 임시 가격 문구. 쿠팡 링크·구매 시작은 6단계

## 5. 예산 확인, 버전 B (F2)
- 2026-10-23 구현: 별도 화면 대신 장보기 목록 위 '예산' 칸(슬라이더, 비교 막대, 교체 제안 카드)
- 예산 입력 칸, 예상 합계와 예산 비교 막대
- 초과 시 경고와 교체 제안 카드
- "그대로 진행", "교체 제안 적용"

## 6. 보관 안내 (E1~E4)
- 2026-10-23 구현: 별도 화면 대신 장보기 화면의 [장보기 목록 | 보관 방법] 탭. 조리일은 선택 상자로 변경, 냉동 끼니 아래에 "전날 밤 냉장실로 옮기기", 냉동이 맞지 않는 메뉴가 냉장 기간을 넘으면 경고
- "조리일 10/25(일)"과 "변경" 버튼
- 날짜별 목록: 월 10/26 냉장 불고기, 화 10/27 냉장 덮밥, 수 10/28 냉장 불고기, 목 10/29 냉동 덮밥, 금 10/30 냉동 불고기
- "10/28(수) 밤에 할 일: 목요일 덮밥을 냉장실로 옮기기"
- 보관 온도 안내
- 하단 "다음 주 계획하기"
